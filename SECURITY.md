# Security and private data

Do not attach full saves, account identifiers, secrets or local game caches to public issues. Share a minimal reproduction, version information and redacted error text instead.

For sensitive reports, use GitHub's private vulnerability reporting if it is enabled for this repository. If it is not enabled, open a minimal issue requesting a private reporting channel without including exploitation details or private data.

This is experimental local-file editing software. Back up independently and use it offline with the game closed. No edit is guaranteed safe for online play.
