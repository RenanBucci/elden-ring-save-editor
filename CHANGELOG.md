# Changelog

## 1.0.0 public preview

- React and Tauri application with a Rust save-editing core.
- Character, inventory, build, world, appearance, backup and slot tools.
- Explicit Save and complete Save copy controls.
- English and Brazilian Portuguese translations and responsive item grids.
- Permanent risk notice; internal equipment placeholders hidden.
- Public-source cleanup: no personal saves, old Electron application, debugging reports, game wallpapers or bundled extracted icons.
- Local optional icon cache, standalone build instructions and a CI configuration template.

This preview still requires independent in-game testing. See the limitations in the README.
